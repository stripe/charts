# Project information

Stripe maintains this package. Version 0.0.1 is an early release, with more to come as Stripe Charts evolves.

## Feedback and bugs

If a chart isn’t working as expected, please [open an issue](https://github.com/stripe/charts/issues)
with the smallest example spec that shows the problem, what you expected,
and your browser and package version. Use fictional or anonymized data.
Feedback about reporting needs helps us understand where the library should
go next.

For running or adapting the source, see the [development guide](docs/development.md).
The [reference](docs/reference.md) documents the supported API and behavior.

## Security

Please report security vulnerabilities privately through Stripe’s
[vulnerability disclosure program](https://hackerone.com/stripe), rather than
in a public issue.

## Contributor License Agreement

If a code change is submitted, Stripe’s [CLA Assistant](https://github.com/CLAassistant)
will request a Contributor License Agreement signature before it can be merged.
